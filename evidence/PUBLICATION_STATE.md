# 한국어 독립 출판 상태 — 1.0.0

이 판본의 지적 대상은 에미 뇌터 유지 대상 저작의 완전한 한국어 누적판이다.
43개 번호 논문, 번호 뒤 별도 저작 A와 B, 참고문헌·판본 부록을 포함한다.
P32는 32번 논문일 뿐 별도의 공개 대상이 아니다.

활성 독일어 권위는 v047/ED0011이다. sp11.csv의 48개 범위가 논리행
1–24,146을 중복이나 공백 없이 정확히 한 번 덮는다. prov12.csv의
47개 유지 대상 TeX는 모두 동결 신원과 일치한다. 알려진 미번역 범위와
미해결 한국어 내용 결함은 0개다.

공개 리더는 519쪽이며 DOI 표지, 링크형 목차, 전체 본문으로 구성된다.
고정 시각 4회 빌드의 마지막 두 PDF가 바이트 동일하다. ToUnicode 보정
뒤 모든 글꼴과 두 추출기가 건전성 검사를 통과했다. 519쪽 전체가 렌더되어
21개 연락판으로 검사되었고 경계·탐색 페이지 6쪽을 고해상도로 재검사했다.

번역·교정·조판의 전체 감사 가능성을 위해 원문 권위, 범위·용어·차이 원장,
독립 점검 반환, 빌드·추출·렌더 증거, 원시 Codex 작업 기록의 정적 사본,
거버넌스와 출판 방법을 증거 ZIP에 묶는다. 자격증명 파일이나 토큰 값은
포함하지 않으며, 패키징 전에 실제 토큰 값과 대조한 비밀정보 검사를
통과해야 한다.
